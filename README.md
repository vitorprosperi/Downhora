Downhora 

1. Pré-requisitos

- Node.js: Baixe em https://nodejs.org/
- Git: Baixe em https://git-scm.com/
- Github Desktop: https://desktop.github.com/download/
- Expo Go (Celular): Instale via Play Store ou App Store

2. Clonar o Repositório
- cd dhapp 

3. Instalar dependências
- npm install
- npm install -g expo-cli

 4. Comandos
- Iniciar o projeto: npx expo start

*Comandos Git:
- git branch:           # Verifica em qual branch está trabalhando
- git status            # Ver arquivos modificados
- git add .             # Adiciona tudo para commit
- git commit -m "mensagem"  # Cria o commit
- git checkout (nome-branch)# Muda de uma branch para outra
- git merge (nome-branch) # Adiciona os arquivos da nova branch na branch principal
